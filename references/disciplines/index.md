# 按学科和文稿用途选读

此页只帮助定位。选中后打开对应文件；不同时读取下表所有文件。

| 稿件涉及的学科 | 需要解决的写作任务 | 对应 Reference |
|---|---|---|
| 文学、语文、文本解读 | 细读片段、书评、表达赏析；将判断接回文本 | [文学与文本](literature.md) |
| 历史、文博 | 史料介绍、历史解释、展品说明；处理年代和解释分歧 | [历史](history.md) |
| 哲学、伦理 | 概念讨论、论证、反驳；保留争点与前提 | [哲学](philosophy.md) |
| 社会学、心理学、政治研究 | 研究片段、调查解读；区分操作定义、观察与解释 | [社会与心理](social-psychology.md) |
| 教育、语言教学 | 教学设计、课堂反思、学习研究说明；区分计划与实际表现 | [教育与语言教学](education.md) |
| 数学、统计 | 定义、推导、证明、数值解读；保留量词、模型与不确定性 | [数学与统计](mathematics-statistics.md) |
| 物理、化学、生物、地球与环境科学 | 科普、实验结果、机制说明；连接观测、方法和解释 | [自然科学](natural-sciences.md) |
| 工程、计算机、AI | 教程、设计说明、故障解释；处理版本、条件与操作 | [工程与计算机](engineering-computing.md) |
| 医学、公共卫生 | 研究说明、健康科普；保留研究人群和比较条件 | [医学与健康](medicine-health.md) |
| 经济、金融、管理 | 数据评论、研究摘要、经营分析；统一口径并解释选择 | [经济与管理](economics-business.md) |
| 法律、公共政策 | 案例分析、制度说明、政策备忘；处理法域、规则与适用 | [法律与政策](law-policy.md) |
| 艺术、设计、视觉研究 | 作品分析、展览文字、设计说明；从观察形成判断 | [艺术与设计](arts-design.md) |

研究论文片段要保留学科中的论证和报告要求；科普按读者需要解释，不能把条件删掉；教学稿按学习任务展开。格式由当前作业、机构或期刊要求决定，不因学科名称就默认 IMRaD、APA、IEEE 或固定篇章。

同一材料可能属于不同任务：历史统计稿以史料问题为中心时读历史，以估计方法为中心时读数学统计；AI 医疗产品页先选品牌场景，研究效果的表达再选医学。每次增加参考都应解决一个具体写作问题。

未覆盖的细分领域，从最近的写作任务出发，保留该领域术语和主张条件；若已有参考无法处理关键区别，查当前领域的真实原文后再构思。不要编造一条领域惯例。新找到的样本先用于当前任务，持续修改 skill 需要用户授权。
