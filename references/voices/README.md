# 声音档案

替一个具体的人写他要念、要署名的话时，先看这里有没有他的档案。档案里的习惯优先于本 skill 的一般建议，包括“口播用短句”这类默认；事实和署名的规矩不变。

公开版本不附带个人声音档案。使用者可在本地添加自己的改稿与录音对照。

## 怎么建一份

办法见 [../voice.md](../voice.md)「从改稿里学一个人的声音」。档案照下面的样子写，越短越好，例句全用他真说过、真改过的句子。

```markdown
# <名字> 的声音档案

## 先知道这几件事
档位（讲给大家听／跟一个人聊／对一个人讲清楚），句子长短，他从来不说的话。

## 来源
每份材料：日期、哪一期或哪一封、原稿在哪、他的版本在哪，是改稿还是开口时的偏离。

## 他改了什么
按习惯分组，每组两三对“原句 → 他的”，注明来自改稿还是录音。

## 他留着没改的
同样重要：哪些短句、哪些说法他认了。

## 用量
数出来的：多少字里出现几次。写明怎么数的。

## 写的时候
五六条，能直接照着做。

## 还缺什么
哪些场合还没有样本。
```

每有一份新的改稿或录音，就把新的对照补进去。他改得越来越少，说明档案对了；他又在同一类地方改，说明那一条写错了或者写得不够具体。
