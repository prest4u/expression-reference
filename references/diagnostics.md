# R-DIAG｜上下文敏感的 anti-slop

按问题取用，非必跑八项。词语、抽象、重复、被动、转折、三分结构只是线索；先定位、解释当前读者影响，再保意修改。无实质问题不为“更像人”强改。

| ID / 位置 | 场景理由 | 正当例外 | 改进 |
|---|---|---|---|
| D1 判断无依据/选择意义 | 口播不知做什么，科技不可判断，品牌难辨识 | 精准概括、正文支撑标题、导航 | 已有动作/条件/关系承接；缺材料问关键缺口/降低主张 |
| D2 相邻/收尾同义重复 | 耗时不推进 | 教学回扣、导航、叙事变化、识别词 | 查再次出现的用途；无新作用的解释实际删/合并，有意回扣/节奏可留，不设删字率 |
| D3 UI/数字/感官/现场/对白无据 | 假可信，改材料/身份 | 授权虚构创作、真实素材 | 核输入；同事实比较不能借虚构加料；未知待核 |
| D4 结构与任务不合 | 整齐却中心不清 | 预告/总结、采购对照、分层 | 依处境/问题/区别/观察选中心，不禁三点/转折 |
| D5 修辞/术语替代关系 | 记住气势却不能判断 | 类比、命名、诗性、精准抽象 | 正文承接，可删可展开，不强制故事化 |
| D6 能力/量词/因果/承诺超范围 | 误解效果、时态和来源 | 范围内确定结论；语境揭示小说反讽 | 条件贴近主张，分宣称/观察/推断，不一律模糊 |
| D7 句法/重心/语用不适配 | 要反译，fusion 无功能 | UI 名、术语、文学陌生化 | 目标语言重组关系，核 only/not 等范围 |
| D8 代认经历/心理/收益 | 假装亲密或越权保证 | 授权关系、明确拟想、确认且有权限承诺 | 调距离，写事实/选择，不借经历/普遍化我喜欢 |

输出可仅一两项：位置→影响→建议/例外。判断落实到当前稿的删、并、移或展开；材料/关系/行动应承担表达判断，不靠自我宣告。事实成立不等于都该写入：保留影响主张的必要条件，未知首先限制承诺，仅影响当前读者选择时才呈现，可给依已有事实成立的待验证行动，不冒充已发生效果。允许张力、感官与节奏承担功能，不以最短或最少修辞获胜。合法但平庸可重选中心，事实通过不等于表达好。审美多答案，事实、引用和承诺的含义要准确。

## 本地 Humanizer CN 的选择性借鉴

2026-10-13 读取本机 humanizer-zh/SKILL.md 的核心规则、内容与语言模式、处理流程、输出及完整示例。借用删填充、将空泛主张接到具体内容、保留原义与语气、通读成稿的方法；无需为此另载整份技能或加评分表。

具体内容也会写错。该文件的完整示例在原稿未给功能和反馈时加入了批处理、快捷键、离线模式以及测试用户速度反馈；这种改写会新增事实。当前技能只用已给细节。第一人称、情绪、句长或修辞按作者材料与本题选择，不为自然感制造经历，不按固定词表或排比数量修改。

通读时核对新加的主语、动词和限定：规格是否变成性能，计划是否变成已完成，未报告是否变成不可能判断。修复对应句子即可，不默认输出核对过程。
