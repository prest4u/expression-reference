# 纪实、散文、人物故事与虚构

## 速用

先确认作品的真实性要求和作者拥有的材料。纪实保留可追溯的事实与引语；虚构允许按授权创造。人物故事不自动等于品牌故事，也不要求每篇都有冲突和反转。

参照 [Kane 描写与叙事选读](../sources/kane.md)、[《文章自在》已读试读](../sources/books.md#bk-zhang)，并保留原有文学作品的分析。需要具体技巧时读[叙事方法](../craft/narrative.md)。以下案例均为原创。

## 按材料形态进入

| 手头材料 | 适合的处理 | 需要补充时怎么做 |
|---|---|---|
| 采访录音或逐字稿 | 选真实段落，保留说话人及语境 | 不清处回听或标注 |
| 作者口述经历 | 先整理时间、人物、动作和作者感受 | 询问会改变叙述的缺口 |
| 新闻或档案资料 | 区分记录、报道和解释 | 核日期、来源与转引 |
| 只有一项成果 | 写准确的成果说明或短观察 | 不制造完整奋斗故事 |
| 明确的小说任务 | 按人物处境、视角与风格创作 | 保持内部一致性 |
| 教学示例故事 | 声明为假设或虚构例子 | 不包装成真实个案 |

## 人物特写

选择能表现人物处境的动作和决定，并让读者理解其约束。不要只叠加“坚韧”“热爱”“有温度”等评价，也不要靠苦难自动制造崇高形象。

真实人物的心理只在有采访、自述或可靠材料支持时表达。外部叙述者可以写“她停顿了”，前提是记录中有该动作；“她终于释然”需要人物自述或合适的叙述身份。

资料不足时，简洁说明比填满场景更可用。不要把编辑者的想象冒充作者亲历。

## 散文与回忆

回忆可能存在不确定日期、对话和细节。保留作者明确的记忆性质，例如“大约”“记得”；不把它润色成档案式确定。用户想写文学化回忆时，可以调节顺序、重音和意象，同时保留事实身份。

描写围绕作者注意到的对象展开。若某个细节推动后文理解，可反复出现；没有变化的装饰性细节可删。情绪不必每段命名，必要的思考也不必一概藏起来。

## 虚构叙事

从人物在当前场景中想做什么、遇到什么阻碍、做出了什么选择寻找推进。阻碍可以来自关系、误解、环境或自身判断；不必每次设计敌人。行动的后果使场景变化，背景在读者需要时进入。

视角决定读者能知道什么。有限视角下突然报告另一个人物未表达的内心，会改变叙述方式；可以有意改变，但须有作品上的理由。让对白符合人物所知和关系，不让人物轮流替作者讲解设定。

## 原创比较：同一素材，不同写法

给定纪实材料：一位修表师在退休前把工作台交给徒弟；没有录音，也未提供具体对白。
准确概述：“退休前，他把工作台交给了徒弟。”
可以继续写工作台和交接过程，但必须取得真实材料。

若用户明确授权虚构，可另写：“他把放大镜留在灯下，手伸到一半，又把抽屉关上。”这属于虚构选择，应在当前任务身份中保持清楚。它不能回填到真实人物稿中。

English nonfiction version with the same supplied fact: “Before retiring, the watchmaker handed his workbench over to his apprentice.”
An added description of trembling hands or a whispered farewell would introduce facts that were never supplied.

## 品牌与个人经历

品牌可以讲真实创作过程、服务实践或客户故事，仍须有相应材料和使用许可。用户体验不能由作者个人故事推定；一个故事不能替代产品性能说明。

已经授权的虚构广告创意可以有戏剧性，但成品应避免让受众误认成真实客户自述。产品和健康主张仍从实际资料取得。

## 编辑时保留什么

保留作品有意的留白、重复、粗粝与节奏。润色可以修歧义或冗余，但不把所有人物都改成同一种礼貌声音。用户要求保留对白时，按其范围处理；源文引语保持准确。

交稿前核故事内的时间、称呼、视角和因果连续性。作品尚在探索时，可以给不同观察方向，差异应来自材料与叙述选择，不能只换形容词。
