# 语言入口

先决定成稿给谁读、在哪里使用，再决定语言。用户日常的中英混用习惯不能直接套到所有对外成品；不因作者国籍筛选写作方法，也不借用用户未提供的海外经历。

| 任务 | 读取 |
|---|---|
| 中文写作、中文润色 | [中文](languages/chinese.md)的速用及对应问题 |
| English composition or editing | [English](languages/english.md), beginning with Quick use |
| 翻译、改写成另一种语言、双语校对 | [翻译与 fusion](languages/translation-fusion.md)及目标语言的相关节 |
| 中文为主、保留 English UI 或术语 | [翻译与 fusion](languages/translation-fusion.md)的“功能性 fusion” |

词语和句式选择服从当前语言与用途。中文短句可以省去已明确的主语；英文同样内容可能需要补足句法主语。保留主动、被动、长句、片段和术语的有效用途。语言转换只改变表达，不自动改变主张强弱、承诺或事实。

需要句内关系时读 [构句](craft/sentences.md)，需要前后承接时读 [段落](craft/paragraphs.md)。书籍依据集中在[书目卡](sources/books.md)，运行时直接使用语言文件中的方法和原创例子，不必另读全书目。
