# 中文：写出像人说的话

## 好中文的底子

好中文不是华丽，是准确、干净、有口气、有节奏。这件事前人讲得很透，值得记住几处：

- **胡适《文学改良刍议》（1917）** 提了八条，其中“须言之有物”“不作无病之呻吟”“务去滥调套语”，一百多年后依然是对付 AI 腔最好的药方。
- **鲁迅《答北斗杂志社问》**：写完至少看两遍，把可有可无的字、句、段删去；也不要生造除了自己谁也不懂的形容词。
- **汪曾祺** 认为语言不是内容的外壳，语言本身就是内容，所以说“写小说就是写语言”。他的散文（《端午的鸭蛋》《人间草木》）短句多，口语多，白描多，留白多，没有一个字在用力。
- **吕叔湘、朱德熙《语法修辞讲话》（1951）** 系统整理了用词、造句、标点上的常见毛病。今天模型写出来的很多病句，在这本书里都能找到病例。
- **余光中《怎样改进英式中文》** 和 **思果《翻译研究》** 专门讲欧化中文：名词化、“的的不休”、被动泛滥、代词泛滥。AI 中文最大的病根就在这里，因为它读过的中文里，有大量翻译腔。
- **朱光潜《咬文嚼字》**：斟酌一个字，其实是在斟酌一个意思。

## 欧化和翻译腔

| 毛病 | 原句 | 改 |
|---|---|---|
| 名词化：进行/作出/加以/予以/实现 + 名词 | 对方案进行了深入的研究 | 仔细研究了方案 |
| | 作出了重要贡献 | （说出具体做了什么） |
| “的”字串 | 我们公司的产品的设计的理念 | 我们产品的设计理念 |
| 被动泛滥 | 这个问题被大家讨论了很久 | 这个问题大家讨论了很久 |
| | 文件已被上传 | 文件已上传 |
| 代词泛滥 | 他打开了他的电脑，他发现他的文件不见了 | 他打开电脑，发现文件不见了 |
| “当……的时候” | 当你打开设置页面的时候 | 打开设置页后 |
| “作为一个……” | 作为一个产品经理，我认为…… | 我做产品，我的看法是……（或直接说看法） |
| “对于……来说” | 对于新用户来说，这一步比较难 | 新用户会卡在这一步 |
| “一个”滥用 | 这是一个非常好的方法 | 这个方法很好 |
| 连接词过密 | 因为下雨了，所以比赛取消了，因此我们改期 | 下雨，比赛取消，改期了 |
| “通过……使……”（主语消失） | 通过这次培训，使大家掌握了新流程 | 这次培训后，大家掌握了新流程 |
| “在……方面/层面/维度” | 在用户体验层面存在一定不足 | 用户用起来不顺：（具体哪里） |
| “具有……性” | 具有很强的实用性 | 很实用（最好说出用在哪） |

表里“代词泛滥”“连接词过密”两行说的是书面文字。口播里对着一群人讲，听众没法回看，很多说话人会把主语和“而”“于是”说出来（“他说他一直没有找到……”“于是就自己做了一个”）。替这样的人写口播，照他的样本，别按这张表删。

被动句在中文里本来多用于不如意的事（“被骗了”“被批评了”）。中性的被动，中文常用意念被动：“信寄出去了”“饭做好了”，不需要“被”。

## 汉语自己的长处

模型写中文时，常常把汉语当成另一种语法的英文。其实汉语有几样英文没有的好东西：

- **话题—评论。** “这件事我有不同看法。”“那家店，菜一般，环境好。”先立话题，再评论，不需要严格的主谓宾。
- **流水句。** 几个动作一路推下去，靠语序和意合，不靠连接词：“下了班，买两个烧饼，边走边吃，到家天就黑了。”
- **零主语和话题链。** 一个话题开头，后面几句承接它，主语省掉。话题换了才重新点明。
- **动词丰富。** 拎、提、端、捧、挎、扛、搬、抱，选准了动词，形容词就省了。“他捧着那份合同”比“他小心翼翼地拿着那份合同”好。
- **四字格。** 凝练、有节奏。一句里一个，是点睛；一句里四个（“高效便捷、安全可靠、简洁优雅、智能贴心”），就是套话。
- **语气词。** 吧、呢、嘛、啊，在口播和对话里让话有了口气。书面文字里少用。每个人用法差很多：有人只在话题后面停一下（“今天呢，我来……”“第三个呢，就是……”），从不在句尾说“吧”“啊”。照样本放，位置比数量要紧。

## 节奏

- **单双音节。** 双音节显得庄重，单音节显得利落。“观察”“看”“进行观察”各有分寸。搭配上，单配单、双配双更顺：“种树”“种植树木”都顺，“种植树”就别扭。
- **长短交替。** 长句铺开，短句收住：“我们试了三种办法，换了两个供应商，加班加了一个月。没用。”
- **句尾落点。** 句末是重音，要强调的放在最后。“这个方案最大的问题是贵”，读者记住的是“贵”。
- **四字格和散句搭配。** 全是四字格像对联，全是散句又可能松，交错着用。
- **读出来。** 中文的节奏只能用耳朵检验。

## 腔调

不同的腔，在它自己的场合是规范，挪到别处就是腔。

| 腔 | 特征 | 在哪里是正当的 | 挪错地方的样子 |
|---|---|---|---|
| 公文腔 | 特此通知、鉴于、兹、有关事宜、相关部门 | 正式公文、规章 | 给客户的邮件里写“特此说明” |
| 学术八股 | 本文旨在、具有重要的理论意义和实践价值 | （其实哪里都可以写得更清楚） | 科普文章开头 |
| 营销腔 | 颠覆、极致、重新定义、匠心 | 极少数真有其事时 | 什么都“重新定义” |
| 平台腔 | 姐妹们、谁懂啊、建议收藏、yyds | 真实用户在真实平台说话 | 品牌官方号硬学 |
| 鸡汤腔 | 愿你、余生、温柔、岁月 | 私人的、真诚的祝福 | 产品发布稿 |
| 互联网黑话 | 赋能、抓手、闭环、颗粒度、对齐 | 团队内部真有共识的术语 | 对外文字、给不在圈里的人 |

AI 腔的完整清单见 [../machine-tells.md](../machine-tells.md)。

## 口语和书面

- **口播稿：** 口语词，关键词可以重复，少用“之”“其”“予以”这类书面虚词。句子长短看说话人和档位：对着一群人讲时，很多人的句子比书面还完整，主语和连接词都说出来（见 [../genres/spoken.md](../genres/spoken.md)）。数字说到听众需要的精度：“差不多三成”在口播里比“29.7%”好记，但数字的意思不能因此变了；精度本身重要时（价格、剂量、日期），照原样说。
- **书面：** 可以更紧凑，但不要文言化。“之”“乃”“其”“亦”混在白话里，像穿着西装戴瓜皮帽。
- **叶圣陶提倡的“写话”**：写下来的，念出来要像人话。这是检验口语化最好的办法，也适用于大部分书面文字。

## 标点和排版

- 中文用全角标点：，。、；：？！“”‘’（）《》，破折号“——”占两格，省略号“……”是六个点。
- 顿号用于并列的词，逗号用于分句。
- 中国大陆一般用“”，台湾香港常用「」。一篇里统一。
- 书名号用于书、文章、报刊、影视、歌曲等作品；产品名、品牌名不用书名号。
- 中文与英文、中文与阿拉伯数字之间加一个空格（GitHub 上广为采用的 [中文文案排版指北](https://github.com/sparanoid/chinese-copywriting-guidelines) 是这么建议的）：“用 Claude 写了 3 篇稿”。全角标点和英文之间不加空格。数字用半角。
- 英文专名保持原样的大小写：GitHub、iPhone、macOS、ChatGPT。
- 中文句子里不要用半角逗号和句号。
- 感叹号要省着用，一篇里一两个就够了。
- 机构、出版方或项目有自己的规范时，以它们为准。

## 用词

- **准确先于漂亮。** “推”和“敲”的区别，就是意思的区别。
- **程度副词会通胀。** 非常、十分、极其、超级、特别，去掉之后，句子常常更有力。要表达程度，用事实：“高了一倍”比“大幅提高”有力。
- **成语要用准，** 不要为了显得有文采而堆砌。用错一个成语，比不用伤得更重。
- **称谓：** 给客户和长辈的第一封信用“您”，熟了以后看关系。一篇之内别在“您”和“你”之间跳。

## 修改示例

**工作汇报。**

> 原：本周，在团队全体成员的共同努力下，我们对用户注册流程进行了全面的优化和改进，有效提升了用户的注册体验，取得了阶段性成果。
>
> 改（假设用户提供的事实是：注册从 5 步减到 3 步；这周转化率从 41% 升到 47%；只有一周数据）：这周把注册从 5 步砍到了 3 步，转化率从 41% 升到 47%。只有一周的数据，下周再看稳不稳。

原稿一个事实都没有。改稿全是事实，还多了一句诚实的保留，读起来反而更有底气。

**散文。**

> 原：秋天是一个美丽的季节，它给人们带来了丰收的喜悦和无限的遐想，金黄色的树叶在微风中轻轻飘落，仿佛在诉说着什么。
>
> 改：楼下那棵银杏，一夜之间黄透了。扫地的大爷早上没扫，说等叶子落完了一起扫。

改稿没有一个形容词在用力，靠的是一个具体的观察。写真实的散文时，这样的观察必须是作者自己的；没有，就问作者要。
